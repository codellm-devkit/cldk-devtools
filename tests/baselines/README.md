# Baselines

This directory holds the recorded output of eval runs of the ladder skills. Each file is evidence of
what one skill produced. These files are not fixtures, and no test compares against them.

These files are older than version 0.6.0. The `work_item` and `epic` issue forms still existed at
the time of each run. Therefore the files give instructions to file an "epic" and a "work item".
Those forms were retired on 2026-09-14. The `CHANGELOG.md` file records that change. The tracking
shapes are still correct, but they have new names. The file
`skills/designing-cldk-changes/references/issue-and-pr-tracking.md` gives those names.

These files stay unedited. This is deliberate. A baseline is a record of one run. An edit that makes
a baseline agree with the current guidance makes the record false.

Record these baselines again against version 0.6.0. Then you can use one of them as a statement of
the current behavior.
