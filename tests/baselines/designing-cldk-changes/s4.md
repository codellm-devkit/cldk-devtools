# S4 baseline — issue prose budget

Three agents, same task, no prose guidance (2026-08-19).

CONTAMINATION: not a clean baseline. The plugin is installed in the test environment,
so agents can read epic-and-issue-templates.md, and the repo's tracker already held
five issues written in this format. All three reproduced the section structure. What
the baseline does establish is length and content discipline, which none of them met.

Result: all three ~900-1000 prose words.
- A: own headings (Summary / Evidence / Why it matters / Proposed direction). No
  SCOPE BOUNDARY. Added an implementation proposal.
- B: template-ish sections plus Impact and Suggested shape. Longest of the three.
- C: closest to the template; still ~900 words, still added a solution sketch.
None marked an unverified claim.

With the reference (2 agents):
- D: 426 prose words. Template section names, no extra sections, used
  "(unverified: which SDKs read it)", measured counts with method.
- E: ~500 prose words (estimated). Same shape, no extra sections, no unverified marker.

Shape converged 2/2. Length 6-25% over the 400-word cap, which is why the budget was
restated structurally (PROBLEM is two paragraphs; a CAVEATS bullet is one sentence)
rather than as a number to approximate.
